# Frontend only — no backend required yet

Run the development server:

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Pages

**Public Portal:** Home, About, Admissions, Academics, Departments, Faculty, Placements, Scholarships, Hostel, Library, Events, Clubs, Transport, Notices, Documents, UniSphere AI Chat

**Admin Portal:** `/admin/login` → Dashboard, Documents, Notices, Events, Analytics, Settings

All data is dummy/mock data from `src/lib/data.ts` and `src/lib/mockChat.ts`.
